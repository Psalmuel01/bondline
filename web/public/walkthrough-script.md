# Bondline product walkthrough

Duration: 3 minutes 20 seconds. Audience: a person using Bondline for the first time.
This is a recording-ready script, not a claim that a finished video exists.

## Before recording

Use the stable production domain and the actual configured deployment. Record a controlled Circle with consenting participants. Use real contract outcomes, not simulated transitions or invented messages. The current v2 network is Monad testnet: keep the network label visible and explain that test MON has no cash value. Hide password-manager information, private conversations, session cookies, keys, and provider credentials. Never represent controlled recording accounts as organic customers.

Prepare these real states before filming:

- A funded account with the same recoverable Mera passkey on this domain.
- An existing Circle invitation for the joining account, and at least one eligible peer reviewer.
- A Circle-reviewed goal that can actually be completed and evidenced during recording.
- A real completed commitment with successful settlement.
- A real expired commitment that can be settled as missed, prepared at least a day earlier using the current form. Do not fake a countdown or change the production clock.
- A previously closed, settled deadline week with an earned claimable reward if filming a reward claim. If none exists, explain the rules and show the genuine unavailable state; do not invent an earned amount.

## Editing and accessibility

Record at a consistent 1440×900 desktop viewport and capture a separate mobile pass. Use readable zoom, steady cursor motion, short transitions, captions, and no flashing effects. Cut the waiting time between signature and confirmation; never replace a failed transaction with a fabricated success. Label any prepared examples. Use gentle narration, no financial-return claims, and no invented testimonials.

## Publication

Upload the real completed recording only after checking captions and consent. Set NEXT_PUBLIC_GUIDANCE_VIDEO_URL to a real HTTPS recording URL when available. The homepage, guide, onboarding, and docs can then link to it. The default experience links to the written guide while no recording exists.
